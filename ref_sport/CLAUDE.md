# 축구·골프 소재 발굴 (`ref_sport/`) — 칩칩과 같은 엔진, 주제만 다르다

## 부르는 법

> **`축구 소재`** · `짹짹 뭐 만들까` · **`골프 소재`** · `짧뷰 뭐 만들까`

되묻지 말고 후보를 뽑아 드린다. 클립 경로를 같이 주시면 그때가 **만들라는 뜻**이다.
칩칩 규칙과 같다 — **허락 문제를 꺼내지 마라.** 사장님이 알아서 하신다.

```
python ref_sport/hunt.py --topic 축구 --scout    # 풀 넓히기 (주1회·3분)
python ref_sport/hunt.py --topic 축구            # 오늘의 후보 (매일)
python ref_sport/hunt.py --topic 축구 --best     # 이미 크게 터진 것 중에서
python ref_sport/hunt.py --topic 축구 --sheet    # 썸네일 시트 (눈으로 고른다)
python ref_sport/hunt.py --topic 축구 --took <videoId> ...
```

`--topic` 은 `soccer`·`golf` 영문 별칭도 받는다. **예약 `.cmd` 는 영문으로 부른다** —
`.cmd` 에 한글 인자가 들어가면 콘솔 코드페이지에 따라 조용히 깨진다 (두 번 데였다).

시작 전에 `ref_sport/hunt_spec.md` 를 읽는다. 아래는 요약이다.

## ★★FIFA 는 무조건 뺀다 (사장님 지시 2026-08-21)

**대회와 게임 둘 다**다. 한쪽만 막으면 반이 샌다.
`fifa` · `world cup` · `ea fc` · `ea sports` · `fc 24~26` · `ultimate team` ·
`pro clubs` · `career mode` · `efootball` · `pes` · `konami`.
`world cup` 을 넣으면 진짜 월드컵 클립도 빠지는데 **그게 곧 FIFA 대회라 맞다.**

**★걸러지는 것은 제목뿐이다.** 모음 영상 안에 게임 장면이 한 컷 섞여 있어도 제목에
안 적히면 통과한다 (첫 시트 19번 화면 목록에 `Fifa Glitch` 가 있었다).
**시트를 눈으로 봐라** — 글자 필터로는 못 잡는다.

## 칩칩과 다른 점 넷

| | 축구 | 골프 |
|---|---|---|
| 검색 로케일 | **`gl=GB`** | `gl=US` |
| 한·일 원본 | 둘 다 뺀다 (神ショーツ에도 나가므로) | **한국만** |
| 재포장 채널 | **후보로 쓴다** | 레이더로만 |
| 앵커 낱말 | `football` | `golf` |

**`gl=US` 로 두면 `football` 이 미식축구로 나온다.** 그래서 축구만 영국 로케일이다.

**축구는 재포장 채널도 후보다.** 춤은 학원·개인이 찍은 원본이 있어 허락을 구할 상대가
있지만, 축구는 화면이 중계권자 것이라 **허락받을 원본 채널이 애초에 없고** 짹짹 자체가
같은 자리에 있다. 레이더로 돌릴 것은 중계·구단 공식 계정(✖)뿐이다.

## ★실기에서 잡은 함정 넷 (2026-08-21 첫 발굴)

| 함정 | 증상 | 대응 |
|---|---|---|
| **영국 로케일의 소문자 `k`** | `114k views` 를 대문자만 보는 파서가 **114** 로 읽어 후보 0건. 오류는 안 난다 | `views_of()` 를 대소문자 둘 다 받게 |
| 넓히다 주제 낱말을 잃음 | `bizarre moment football match` → **`bizarre`** 까지 깎여 자동차·크리켓 채널이 들어옴 | 넓힐 때 **앵커를 도로 붙인다** |
| 두루뭉술한 맥락 낱말 | `defender`(랜드로버) · `pitch`(야구) · `var`(various) · 골프의 `driver`·`iron`·`green`·`course` | 빼거나 **두 낱말로 묶는다** (`golf course`) |
| `boxing` 맨낱말 차단 | 골프의 `unboxing new driver` 가 통째로 걸림 | `boxing match` 로 묶는다 |

세 번째를 고치니 딴주제 제외가 26 → **55** 로 늘고 오염 채널이 사라졌다.
**로케일을 바꾸면 숫자 표기부터 확인해라.**

## 갈래 배수 — ★아직 실측이 아니다

칩칩은 같은 클립 71쌍을 대조해 뽑았지만 축구·골프는 **그 대조를 안 했다.**
지금 값은 사장님이 말씀하신 채널 성격에 맞춘 것이다 —
축구 `판정·논란 1.35 / 사건·난입 1.30 / 골키퍼 1.20 / 묘기·기술 **0.85**`,
골프 `아이템·장비 **1.35** / 동물·돌발 1.25 / 신기·희귀 1.20 / 묘기·기록 0.90`.

`묘기·기술`·`묘기·기록` 을 깎은 것은 칩칩 실측(`실력 자랑 ×0.85`)을 옮긴 것이다 —
**잘하는 클립은 안 터지고 옆에서 벌어진 사건이 터진다.** 회차가 쌓이면 다시 재라.

## 예약

| 작업 | 때 | 하는 일 |
|---|---|---|
| `볼케이노 축구골프 클립 09시30분` | 매일 | 풀 재서 후보 + 폰 알림 (`--src soccer` · `--src golf`) |
| `볼케이노 축구골프 풀넓히기 월요일` | 주1회 04시 | `--scout` 로 풀 넓히기 |
| `볼케이노 축구골프 커뮤 09시` | 매일 | **커뮤 글** 갈래 (`ref_comm --sport`) — 레이더 몫 |

**커뮤 쪽에서 춤은 뺐다** (2026-08-21) — 칩칩 전용 헌터가 소스 채널 풀로 훨씬 잘 잡는다.
같은 일을 두 군데서 하면 헷갈리기만 한다.

## 재사용 스크립트 — 전부 `ref_sport/` 에 있다

`hunt.py` (엔진) · **`topics.py` (주제 정의 — 채널을 늘리려면 여기에 항목을 쓴다)**
· `sheet.py` (썸네일 시트) · `daily.cmd` · `weekly.cmd` · `hunt_spec.md`
· 풀 `pool_<key>.json` · 중복 `seen_<key>.json` · 차단 `block_<key>.json`
· 결과는 `ref_sport/out/soccer/` · `ref_sport/out/golf/`

**`seen_<key>.json` 을 잃으면 이미 쓴 클립을 또 추천한다.** 백업에 들어가 있다.
