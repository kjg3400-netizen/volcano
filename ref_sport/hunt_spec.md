# 축구·골프 소재 발굴 규격 (`ref_sport/`)

칩칩 헌터(`ref_chipchip/hunt.py`, 2026-08-21)와 **같은 엔진**이다. 주제만 갈아끼웠다.
쓰는 법·구조는 거기 `hunt_spec.md` 를 먼저 읽으면 빠르다. 여기엔 **다른 점만** 적는다.

| | 축구 | 골프 |
|---|---|---|
| 채널 | 짹짹 `@JJACK_J` · 神ショーツ | 짧뷰 `@짧뷰노노` |
| 검색 로케일 | **`hl=en&gl=GB`** | `hl=en&gl=US` |
| 한·일 원본 | 둘 다 뺀다 | **한국만** 뺀다 |
| 재포장 채널 | **후보로 쓴다** | 레이더로만 |
| 무조건 차단 | **FIFA**(대회+게임)·타종목 | 게임·타종목 |
| 앵커 낱말 | `football` | `golf` |

---

## 쓰는 법

```
python ref_sport/hunt.py --topic 축구 --scout    # 풀을 넓힌다 (주 1회·3분)
python ref_sport/hunt.py --topic 축구            # 풀을 재서 오늘의 후보 (매일)
python ref_sport/hunt.py --topic 축구 --best     # 이미 크게 터진 클립 중에서
python ref_sport/hunt.py --topic 축구 --sheet    # 썸네일 시트 → out/soccer/_후보시트.jpg
python ref_sport/hunt.py --topic 축구 --took <videoId> ...
```

`--topic` 은 `soccer`·`golf` 영문 별칭도 받는다. **예약 `.cmd` 는 반드시 영문으로 부른다** —
`.cmd` 에 한글 인자가 들어가면 콘솔 코드페이지에 따라 조용히 깨진다 (두 번 데였다).

## ★★FIFA 는 무조건 뺀다 (사장님 지시 2026-08-21)

**대회와 게임 둘 다**다. 한쪽만 막으면 반이 샌다.

- 대회 — `fifa` · `world cup` · `club world cup` · `confederations cup`
- 게임 — `ea fc` · `ea sports` · `fc 24~26` · `ultimate team` · `pro clubs` ·
  `career mode` · `efootball` · `pes` · `konami`

`world cup` 을 넣으면 진짜 월드컵 경기 클립도 빠지는데, **그게 곧 FIFA 대회라 맞다.**

### ★한계 — 걸러지는 것은 **제목**뿐이다

모음 영상(`Top 10 …`) 안에 FIFA 게임 장면이 한 컷 섞여 있어도 제목에 안 적히면 통과한다.
첫 시트 19번 `Top Funny & Weird Penalty kicks` 화면 목록에 `Fifa Glitch` 가 있었다
(실기 2026-08-21). **시트를 눈으로 보는 이유가 이것이다** — 글자 필터로는 못 잡는다.

모음 영상은 어차피 그대로 못 쓰고 **한 장면을 뽑아 쓰는 것**이니, 뽑을 때 확인하면 된다.

## ★실기에서 잡은 함정 넷 (2026-08-21, 축구 첫 발굴)

### ① 영국 로케일은 조회수를 **소문자 `k`** 로 쓴다

`114k views`. 칩칩 파서는 대문자 `K` 만 알아서 114,000 이 **114** 로 읽혔다.
문턱 30만을 아무것도 못 넘어 **후보 0건**이 됐는데 **오류는 안 났다.**
`views_of()` 를 대소문자 둘 다 받게 고쳤다.

> 미국 로케일이면 안 났을 버그다. 로케일을 바꾸면 **숫자 표기부터 확인해라.**

### ② 질의를 넓히다 주제 낱말을 잃는다

`bizarre moment football match` 가 0건이라 낱말을 덜어내다 **`bizarre` 한 낱말**이 됐고,
자동차·크리켓 채널을 풀에 넣었다. 이제 넓힐 때 **앵커(`football`·`golf`)를 도로 붙인다.**

### ③ 두루뭉술한 맥락 낱말이 순위를 망친다

`shapes.py`·칩칩과 **같은 함정**이다. 회수를 늘리는 게 아니라 순위를 망친다.

| 뺀 낱말 | 물어 온 것 |
|---|---|
| `defender` | 랜드로버 디펜더 (자동차 채널) |
| `pitch` | 야구 피칭 · 영업 피치 |
| `match` · `manager` · `squad` · `corner` | 어느 종목에나 있다 |
| `var` | `various` 에 걸린다 → `var ` 로 띄운다 |

골프는 더 심하다 — `driver`(자동차) · `iron`(다리미) · `green`(색) · `course`(of course) ·
`tee`(티셔츠) · `chip`(과자) · `range`(범위) · `slice`(조각) · `swing`(그네).
**전부 두 낱말로 묶었다** (`golf course` · `tee shot` · `driving range`).

고치고 나니 딴주제 제외가 26 → **55** 로 늘고 오염 채널이 사라졌다.

### ④ `boxing` 을 맨낱말로 막으면 골프가 죽는다

타종목 차단에 `boxing` 을 넣으면 골프의 `unboxing new driver` 가 통째로 걸린다.
`boxing match` · `boxing ring` 으로 묶었다.

## ★축구는 재포장 채널도 후보다 — 춤과 다르다

칩칩 규칙은 `재포장 채널은 소스가 아니라 레이더다` 인데, **축구엔 그대로 적용하면 안 된다.**

춤은 학원·개인이 찍은 **원본**이 있어 허락을 구할 상대가 존재한다.
축구는 원본 화면이 **중계권자 것**이라 허락받을 원본 채널이 애초에 없고,
짹짹 자체가 재포장 채널과 같은 자리에 있다. 그래서 축구는 `radar_marks = ["✖"]` —
중계·구단 공식 계정만 레이더로 돌리고 나머지는 전부 후보로 쓴다.

골프는 진짜 창작자(장비 리뷰어·레슨)가 많아 기본값(`["⚑","✖"]`)을 쓴다.

## 갈래 배수 — ★아직 실측이 아니다

칩칩은 같은 클립 71쌍을 대조해 배수를 뽑았지만 **축구·골프는 그 대조를 안 했다.**
지금 값은 사장님이 말씀하신 채널 성격에 맞춘 것이다.

| 축구 | 배수 | | 골프 | 배수 |
|---|--:|---|---|--:|
| 판정·논란 | 1.35 | | **아이템·장비** | **1.35** |
| 사건·난입 | 1.30 | | 동물·돌발 | 1.25 |
| 골키퍼 | 1.20 | | 신기·희귀 | 1.20 |
| 신기·황당 | 1.20 | | 실수·해프닝 | 1.10 |
| 실수·자책 | 1.10 | | 규칙·판정 | 1.05 |
| 묘기·기술 | **0.85** | | 묘기·기록 | **0.90** |

근거 —
- 축구는 `신기한거 · 논란 · 댓글폭발할만한거 · 판정잘못` (사장님, 채널 지도 2026-08-20)
  이고 `jjack_spec` 이 `축구·골키퍼 소재` 라 골키퍼 축을 따로 뒀다
- 골프는 `신기하고 재밋는 내용, **제일 좋은건 아이템**` (사장님) 이라 장비를 제일 높게 뒀다
- `묘기·기술` 을 깎은 것은 칩칩 실측의 `실력 자랑 ×0.85` 를 옮긴 것이다 —
  **잘하는 클립은 안 터지고 옆에서 벌어진 사건이 터진다**

**회차가 쌓이면 다시 재라.** 짹짹·짧뷰 카탈로그를 `rss()` + `/shorts` 로 긁어
갈래별 천장(10만↑ 비율)을 보면 칩칩과 같은 방식으로 실측할 수 있다.

## 점수식

```
점수 = log10(조회) × 그 채널 중앙 대비 배수 × 갈래 배수 × 신선도 × 주제맥락
```

- **배수가 절대 조회수보다 중요하다.** 큰 채널의 평범한 편보다 작은 채널에서 터진 편이
  재포장 가치가 높다. 배수 상한 25, 채널 중앙값 바닥 2,000 (작은 채널 독식 방지)
- 주제 맥락이 없으면 ×0.30 으로 깎되 **버리진 않는다** — 눈으로 볼 기회는 남긴다
- `--best` 는 다르다. **이미 터진 것**을 고르는 자리라 `log10` 을 안 쓰고 생조회수를 쓴다
  (칩칩이 여기서 데였다 — log10 이면 9,900만과 100만이 8.0 대 6.0 이라 갈래가 조회수를 누른다)

## 파일

| | |
|---|---|
| `hunt.py` | 엔진 (칩칩 것을 본떴다) |
| `topics.py` | **주제 정의** — 질의·갈래·차단. 채널을 늘리려면 여기에 항목을 쓴다 |
| `sheet.py` | 썸네일 시트 |
| `pool_<key>.json` | 소스 채널 풀 — 쌓인다. 지우면 3분 들여 다시 만들어야 한다 |
| `clips_<key>.json` | 발굴하며 지나친 클립 — `--best` 가 쓴다 |
| `seen_<key>.json` | 쓴 클립. **잃으면 이미 쓴 것을 또 추천한다** |
| `block_<key>.json` | 눈으로 보고 모은 차단 채널 (`{"채널명": "이유"}`) |
| `daily.cmd` | 매일 — 풀을 재서 후보 + 폰 알림 |
| `weekly.cmd` | 주 1회 — 풀 넓히기(`--scout`) |

## 눈으로 걸러야 하는 것

글자로는 못 잡는 채널이 남는다. **시트를 보고** `block_<key>.json` 에 채워 넣는다.
핸들이 아니라 **채널명**으로 건다 — 핸들 철자는 한 글자만 틀려도 오류 없이 안 걸린다.

```json
{ "Some Channel": "이유를 적어 둔다" }
```
