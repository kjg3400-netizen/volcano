# 커뮤형 소재 발굴 — 커뮤니티 11곳에서 '진짜 터진 것'만 긁어 온다

## 부르는 법

> `커뮤 소재 뽑아 줘` · `오늘 커뮤에 뭐 떴냐` · `<번호>번으로 가`

```
python ref_comm/hunt.py                  # 커뮤 11곳 360여 건 → 점수순 (약 45초)
python ref_comm/hunt.py --no-news        # 뉴스 확인 끄고 빠르게 (2초)
python ref_comm/hunt.py --only 잡학       # 갈래 좁히기
python ref_comm/brief.py --pick 2        # 고른 사건의 기사·사진·시트 준비
```

**매일 05 / 11 / 16 / 21시에 저절로 돈다** (윈도우 작업 스케줄러, 2026-08-21 등록).
실시간 베스트는 **54분에 38%가 갈린다**(루리웹 97%·개드립 100%). 한 번만 돌리면
그 순간 걸린 것만 본다 — `--accum-hours 24`(기본값)가 지난 실행분을 합쳐 준다
(실측: 378건 수집 → 누적 709건). 결과는 폰으로도 날아온다.

**★경제 헌터(06/13/20)와 시각이 겹치면 안 된다.** 둘 다 네이버 검색을 두드려서
동시에 돌면 빈 껍데기가 온다(아래 함정표). 그래서 일부러 1시간씩 벌려 놓았다 —
시각을 옮길 일이 있으면 이 간격을 유지해라.

시작 전에 `ref_comm/comm_spec.md` 를 읽는다. 아래는 요약이다.

## ★커뮤는 소재가 아니라 레이더다

네이버 기사는 **매체가 책임지는 보도**지만 커뮤 글은 **개인이 쓴 미검증 주장**이고
남의 저작물이다. 그대로 옮기면 오보가 되고 베끼는 게 된다.

**커뮤로는 "뭐가 터졌나"만 잡고, 사실관계는 기사에서 가져온다.**
`brief.py` 는 일부러 커뮤 본문을 안 긁는다 — 그 사건을 보도한 네이버 기사를 찾아
검증된 `ref_econ/brief.py` 에 넘긴다. 커뮤 반응은 `comm_context.txt` 에만 남아
**훅("커뮤니티가 뒤집힌 이유")** 으로 쓴다.

- 시트의 `기사` 열이 **`❌0` 이면 만들지 마라**
- 건수가 많아도 **겹침이 0.2 미만이면 딴 사건**이다 (교회 글이 무관한 북카페 기사 7건을 물어 왔다)
- 캡쳐를 쓸 거면 **닉네임·프로필 사진·커뮤 로고를 가린다**

## ★조용히 틀리는 곳 — 다섯

| 함정 | 증상 | 대응 |
|---|---|---|
| **태그 안 줄바꿈** | `<li class="li\n li_best2…">` 라 패턴이 안 잡힌다. **펨코·아카 0건, 디시 49→2건** | 파싱 전 `norm_ws()` 로 공백을 뭉갠다. 덤프 스크립트가 공백을 먼저 뭉개서 **눈으로도 안 보인다** |
| 사이트별 눈금 | 디시 추천 890 · 클리앙 추천 1 — 섞어 세우면 디시가 독식 | 그 사이트 중앙값 대비 배수로 환산 |
| 공지·이벤트 | 반응이 커서 상위 독식 (첫 실행 1·2·3위가 더쿠 공지였다) | `NOTICE` 목록 + 공지행 필터 |
| 검색어 말머리 | `[좆됨] 법인 파산…` → 0건 / 말머리만 떼면 10건 | `news_query()` 가 말머리·확장자·자음·은어를 뗀다 |
| 네이버 몰아치기 | 동시 4건↑ 이면 **빈 껍데기(30KB)** — 진짜 0건과 구별 불가 | 동시 3건, 80KB 미만이면 쉬었다 재시도 |

## 갈래 — 경제·정치는 뺀다 (다른 채널에서 다룬다)

`--drop 정치,경제` 가 기본값이다. 오늘치 기준 이슈 185 · 유머 99 · **잡학 30** · 정치 22 · 경제 10.

**★갈래로 자르지 마라, 알맹이로 잘라라.** 유머라서 못 쓰는 게 아니라
알맹이가 없어서 못 쓰는 것이다 — 잡학에도 0.00 이 수두룩하고
(`싱글벙글 절이나 교회를 다니지 마십시오`), 유머판에도 +0.30 이 있다
(`역대급 경제위기라는 이탈리아 근황`). 경제·정치만 빼고 나머지는 남긴 뒤
`fit` 으로 세우고 **시트의 갈래를 보며 눈으로 고른다.**

**잡학**(`~하는 이유`·`~의 비밀`)이 뇌전구와 결이 제일 맞지만 **물량이 제일 적다.**

## ★소스를 늘려 잡학을 채우려 하지 마라 — 해 봤고 실패했다

디시 원본 갤러리를 직접 긁었더니 **미스터리갤=음모론(UFO·백신) · 역사갤=역사왜곡
· 대체역사갤=팬픽 · 싱갤=잡담/짤** 이었다. 넷 다 안 넣었다.

실베에서 본 `싱글벙글 F1에서 상식적인 게 금지된 이유` 는 싱갤의 결이 아니라
**실베가 그중 좋은 것만 걸러 올려준 결과**다. **디시 실베·힛갤이 이미 필터다 —
그 앞단을 긁지 마라.** 답은 소스가 아니라 **누적**이다(위 `--accum-hours`).

## ★펨코는 `/best` 만 긁는다 — 일반 게시판을 건드리면 IP 가 막힌다

`/mystery` 를 몇 번 두드렸더니 **HTTP 430 `에펨코리아 보안 시스템`** 이 뜨고
**`/best` 까지 같이 막혔다**(2026-08-21 실기). IP 단위라 코드로 못 푼다 — 쉬는 수밖에 없다.

포텐터짐(`/best`)은 **이미 전 게시판을 모아 주고**(`category` 로 어느 판인지 나온다),
행 클래스에 **정치 여부까지 박혀 있다**(`li_best2_politics0/1`). 더 긁을 이유가 없다.

시트의 **`⛔ 차단` 과 `⚠ 0건`(구조 변경)을 구별해서 봐라 — 대응이 정반대다.**

## 뚫리는 곳 / 막힌 곳

**뚫림 11곳** — 더쿠(여) · 펨코(남) · 디시실베(남) · **디시힛갤(유머)** · 네이트판(여)
· 루리웹(남) · 클리앙(시사) · 보배드림(시사) · 아카라이브(남) · 인벤(남) · 개드립(유머).
반응 수치가 **목록 HTML 에 이미 다 있어** 네이버처럼 기사별 API 를 안 불러도 된다(1.7초).

**막힘** — 인스티즈·오늘의유머(Cloudflare) · 뽐뿌(403) · SLR클럽(고사).
뺀 곳 — MLBPARK(반응 수치 없음) · 82쿡(갱신 느림) · 이토랜드(약후) · 웃대(이슈성 낮음).

**가장 센 신호는 교차 커뮤 확산이다.** 성향이 다른 판(더쿠+펨코)에 동시에 떴으면 크게 터진 것이다.

## ★커뮤만 쓰지 마라 — 네이버 섹션을 나란히 돌린다

사장님이 뺀 건 **경제·정치**지 뉴스 전체가 아니다. 알맹이 밀도 실측(2026-08-21):

| 소스 | 하루 | 알맹이 0.25↑ |
|---|--:|--:|
| 네이버 IT/과학 | 79 | **48%** |
| 네이버 사회 | 81 | **47%** |
| 네이버 세계 | 82 | 43% |
| 네이버 생활문화 | 78 | 26% |
| 커뮤 11곳(경제·정치 뺀) | 483 | **15%** |

```
python ref_econ/hunt.py --sid 102,103,105,104    # 사회·생활문화·IT과학·세계
```

**새로 만들 게 없다** — 경제 헌터가 `--sid` 를 받고 반응 실측·사건 묶기까지 그대로 한다.

- ※격차를 곧이곧대로 믿지 마라. 알맹이 자가 `공개·논란·1위·최다` 에 점수를 주는데
  그건 뉴스 제목에 원래 흔하고, 같은 사건이 매체별로 중복된다(독파모 5건·중수청 3건).
  **실제 격차는 3배보다 작다.**
- **커뮤를 버리지는 마라.** 새덕후 논란처럼 **커뮤에서 먼저 터지고 기사가 따라오는 것**이
  있고, 그게 이 채널의 차별점이다.

## 구글 트렌드는 소재원이 아니라 가산점이다

`https://trends.google.co.kr/trending/rss?geo=KR` — 공식 피드라 막힐 일이 없다.
낱말 10개 + 검색량(`ht:approx_traffic` 2000+/500+/100+) + 관련 기사 3건씩.

낱말만 와서 그 자체론 소재가 못 된다. **커뮤 글이 트렌드 낱말과 맞으면
그 커뮤 안에서만 도는 게 아니라는 뜻**이니, 경제 헌터의 '전 섹션 랭킹 진입'과
같은 자리에 쓴다.

`hunt.py` (발굴·점수·뉴스교차확인) · `brief.py` (기사 찾아 경제 브리퍼로 넘김)

· 중복목록은 경제와 공용 (`ref_econ/seen.json`, `seed_seen.py`)
