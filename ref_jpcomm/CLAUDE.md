# 일본 커뮤형 소재 발굴 — 커뮤 9계열 17곳에서 긁어 온다

## 부르는 법

> `일본 커뮤 소재 뽑아 줘` · `일본 커뮤에 뭐 떴냐` · `<번호>번으로 가`

```
python ref_jpcomm/hunt.py                     # 17곳 2,500여 건 → 점수순 (약 40초)
python ref_jpcomm/hunt.py --no-news           # 교차확인 끄고 빠르게 (4초)
python ref_jpcomm/hunt.py --show-blocked      # 절대금지로 뺀 것도 본다
python ref_jpcomm/hunt.py --only 生活・マナー論争,逆説・雑学
```

시작 전에 `ref_jpcomm/jpcomm_spec.md` 를 읽는다. 채널은 **ショーフィ(쇼피드)** 로
`ref_jpecon` 과 같고, **대전제(비난 금지·시청자가 일본인)가 그대로 적용된다.**

## ★일본엔 펨코가 없다 — 그래서 여러 곳을 나란히 긁는다

한국은 `fmkorea.com/best` 하나가 전 게시판을 모아 주지만 일본은 그런 곳이 없다.
판이 성별·계층별로 갈라져 있어 **한 곳만 보면 그 판 목소리만 듣는다.**

**뚫림 17곳** — ガルちゃん(인기·신착) · 発言小町(일간·주간) · 5ch(ニュース速報+·芸スポ+·嫌儲)
· はてブ(총합·생활·학습) · Togetter(주목·톱) · ヤフコメ(총합·국내·생활) · ハム速 · 痛いニュース.
전부 `requests` 로 열리고 2,500여 건이 3~4초다.

- **ガルちゃん 인기 랭킹은 `/ranking/` 이 아니라 루트(`/`)** 다. `/ranking/` 은 403
- **5ch 판 서버는 `headline.5ch.io/ikioi/` 에서 찾는다.** `bbsmenu.html` 은 이제 포털이라 안 나온다
- 막힌 곳 — ママスタ(JS 챌린지) · ikioi2ch(고사) · Togetter `/ranking`(JS)

## ★조용히 틀리는 곳 — 여섯

| 함정 | 증상 | 대응 |
|---|---|---|
| 인코딩 3종 | 5ch=**cp932** · 痛いニュース=**euc-jp** · 나머지 utf-8 | utf-8 로 못박으면 제목만 깨진다 |
| 5ch 는 HTML 이 아니다 | `norm_ws()` 를 걸면 줄이 다 붙는다 | **HTML 에만** 공백을 뭉갠다 |
| `★2` 무시 | 続きスレ라 실제는 `(순번−1)×1000＋レス` | 안 세면 5,000레스가 `(120)` 으로 보여 밀린다 |
| ヤフコメ 행 경계 | `newsFeed_item` 은 **없다**(`_body` 뿐이고 링크보다 뒤) → 0건 | `<li data-ual-view-type="list">` 로 자른다 |
| Togetter 행 클래스 2종 | ` clearfix` 만 잡으면 25건 중 10건 | `[^"]*clearfix` |
| 검색결과 `<em>` | 검색어가 쪼개져 **겹침이 전부 0.00** | `<em>` 을 먼저 지우고 기사 id 로 묶는다 |

## ★★확산은 '사이트 수'가 아니라 '계열 수'로 센다

5ch 세 판과 마토메 두 곳은 **서로 다른 커뮤가 아니다.** 마토메는 5ch 를 베끼고
세 판은 같은 사람들이 판만 옮긴다. 그대로 세면 5ch 화제 하나가 '5개 커뮤 동시 확산'으로
둔갑해 **小町·ガルちゃん 의 진짜 원본 논쟁을 전부 눌러 버린다.**

일본어는 조사가 한 글자라 글자쌍이 우연히 겹치기도 쉽다 —
겹침 하한을 **7쌍**(한국판 4쌍)으로 올렸다. 안 올리면
`こんなテレビ番組が見たい` 가 `こんなところになぜ食パン投棄` 에 붙는다.

## ★★절대금지 층 — 한국판에 없는 부분이다

일본 커뮤 상위권은 **국적·정치·연예인 두들기기**가 태반이다.
실측 2,517건 중 **392건(15%)** 이 걸렸고 **그것들이 반응은 제일 컸다.**

`혐오·국적`(在日·嫌韓·外国人犯罪) · `정치대립`(정당·首相·**知事·市長**) ·
`실명범죄·불행`(逮捕·不倫·**死亡·事故·重体**) · `성인` · `실황·잡담` · `창작물`.

- **말끝만 다르면 그냥 통과한다.** `死亡事故` 만 막았더니 「4人が死亡」이 1위,
  `死亡` 을 막았더니 「接触し重体」가 2위로 올라왔다. **어간까지 내려 잡아라**
- **시트 맨 아래 '만들지 마라' 칸을 반드시 읽어라**

## ★앙케트 잡담이 반응으로 밀고 올라온다

ガルちゃん·小町 상위의 태반이 앙케트다(`2人目を迷っています`·`海外旅行に行ったことない人`).
코멘트는 크게 붙지만 사실이 하나도 없어 대본을 못 쓴다.
**물음표 없는 쪽이 더 많다** — 일본어는 체언으로 끊는다. 그래서 둘로 건다:
짧은 의문형(−0.40) + **나열형**(짧고·숫자도 인용도 없고 `人`·`こと`·`事` 로 끝남, −0.45).

알맹이 가중을 한국판(0.40)보다 센 **0.55** 로 둔 것도 같은 이유다.

## 이 채널이 만들 수 있으면서 댓글이 터지는 자리

대전제로 정치·국적·연예인을 다 빼면 남는 노른자는 둘이다 —
**`生活・マナー論争`** 과 **`世代・価値観`**. 발언소마치·가루짱의 주력이고
뇌전구의 반전 구조와도 그대로 맞는다. `安全` 열이 `+0.45` 이상인 것들이다.
