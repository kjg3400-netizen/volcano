# 경제 소재 발굴 — 네이버에서 '실제로 반응 붙은 것'만 긁어 온다

## 부르는 법

> `경제 소재 뽑아 줘` · `오늘 뭐 만들까` · `<번호>번으로 가`

사장님이 손으로 하시던 **뒤져서 될 만한 것 고르기**를 대신한다.
되묻지 말고 돌린 뒤 시트를 보여 드리고, **뇌전구로 뒤집을 만한 것 3~5개를 추려 추천**한다.

```
python ref_econ/hunt.py                  # 경제 300여 건 → 반응 실측 → 점수순 (약 80초)
python ref_econ/brief.py --pick 3        # 고른 사건의 본문·사진·시트 준비
python ref_econ/seed_seen.py             # 납품 이력을 중복목록에 반영 (회차마다 한 번)
python ref_econ/learn.py                 # 채널 실적 다시 학습 (회차 쌓이면)
```

**매일 06 / 13 / 20시에 저절로 돈다** (윈도우 작업 스케줄러, 2026-08-21 등록).
업로드는 **08 / 17시** — 뇌전구형은 하루 2편이다 (사장님 지시 2026-08-21).
헌터는 3회 그대로 둔다 — 시트가 최신일수록 좋고, 20시치는 다음날 아침 몫이다. 결과는 늘 `ref_econ/out/_최신시트.md`.
사장님이 "오늘 뭐 만들까" 하시면 **새로 돌리지 말고 그 파일부터 열어 봐라** — 이미 있다.

시작 전에 `ref_econ/econ_spec.md` 를 읽는다. 아래는 요약이다.

## ★네이버는 오류 없이 조용히 틀린다 — 네 군데

| 함정 | 증상 | 대응 |
|---|---|---|
| 랭킹의 `sectionId` | **무시된다.** 101·100·생략이 전부 같은 375건 | 후보 풀은 `SECTION_ARTICLE_LIST?sid=` 로만. 랭킹은 가산점 전용 |
| 인코딩 | 랭킹(`.naver`)은 **EUC-KR**, 섹션은 UTF-8 | utf-8 로 못박으면 제목이 깨지고 경과시간이 통째로 빈다 |
| 감정반응 | `화나요`·`좋아요` 는 **없어졌다** (쏠쏠정보·흥미진진·공감백배·분석탁월·후속강추 5종) | '화나요 비율'로 논쟁도를 재려 하지 마라 — 항상 0 이다 |
| `/cluster/` | 사건 묶음이 아니라 **주제 피드**다 (한 묶음에 132건) | 믿고 묶으면 엉뚱한 기사·사진이 딸려 온다. 제목 유사도로 묶는다 |

## 고르는 기준

```
최종 점수 = 네이버 반응 점수 × 채널 실적 배수
```

네이버 쪽은 실측이 주(主)다 — 댓글수, 감정반응, 몇 개 매체가 받아썼나,
전 섹션 랭킹에 들었나, 갓 올라왔는데 벌써 뜨거운가(속도).
`매체` 열이 크면 큰 사건이고, `정보%`가 높으면 정보형이다.

## ★네이버 반응만 믿으면 틀린다 — 채널 실적을 곱한다

네이버에서 반응이 좋아도 **이 채널에서 안 먹히는 꼴**이 있다. 숏단지 15편 실측(2026-08-20):

| 꼴 | 중앙 조회 | 배수 |
|---|--:|--:|
| 한국 vs 해외 | 16,354 | ×1.60 |
| 인물·거액 | 8,102 | ×1.48 |
| 증시·기업 | 4,024 | ×0.99 |
| 제도·거시 | 2,409 | ×0.90 |
| 사연 | 2,658 | ×0.86 |

**첫 추천이 이걸 몰라 틀렸다** — 전세 안심신탁을 `정보% 95` 만 보고 1순위로 밀었는데
제도·거시는 이 채널 최하위 꼴이었다. 잘 되는 편은 **주체가 뚜렷하고 금액이 크다**
(`중국이 52척 싹쓸이`, `455억 번 회장님`). 안 되는 편은 주체가 흐릿하다.

- 배수는 `learn.py` 가 채널을 받아 계산한다. **회차가 쌓이면 다시 돌려라** — 과적합 방지로
  1.0 쪽으로 당겨 둔 축소가 풀리면서 날카로워진다
- 꼴 분류(`shapes.py`)는 **순서가 결과를 바꾼다.** 두루뭉술한 낱말(글로벌·세계)을
  넣지 마라 — 그냥 증시 기사가 ×1.6 을 받아 1위로 올라온다

## ★★중국 소재가 이 채널 최고 꼴이다 — 시트 맨 위 칸을 먼저 봐라

사장님이 먼저 알아채신 것을 실측으로 확인했다 (2026-08-21, 두 채널 21편 전수).

| | 중국 편 | 나머지 | 배수 |
|---|--:|--:|--:|
| 숏단지(한국) | **15,000** (2편) | 4,350 (14편) | **3.45배** |
| 숏피드(일본) | **9,500** (3편) | 3,750 (2편) | **2.53배** |

**양쪽 채널 1·2위가 전부 중국 편이다.** 숏단지는 중국 없는 14편 최고(8,500)를
중국 2편이 둘 다 넘겼다.

### ★낱말이 아니라 구도다 — 이걸 헷갈리면 시트가 오염된다

`「日本製」なのに中国産が入る` 는 중국이 나오는데 **1,200 으로 최저권**이었다.
중국이 배경일 뿐 주제가 원산지 표시 제도라서다. 터진 편은 전부
**자리를 뺏고 뺏기는 구도**다 — `LNG선마저 중국이 싹쓸이` · `삼성을 제치고 중국산 D램`
· `中国客が半減したのに過去最多`.

그래서 `shapes.py` 가 **중국 낱말 AND 대결 낱말** 두 조건으로 건다. 한쪽만으로는 안 된다.
`수출`·`1위`·`위협` 같은 넓은 낱말을 넣으면 무역·ETF·군사 기사가 통째로 딸려 온다(실측으로 뺐다).

### 시트 보는 법

시트 맨 위 **`★중국 소재`** 칸이 이것이다. `◎맞대결` 이 위 구도이고 `○관련` 은
중국이 나오지만 구도는 아닌 것 — **○는 제목을 읽고 직접 고르셔야 한다.**

- **점수 순위로 밀지 않는다.** 배수 상한이 1.6 이라 `네이버 437 × 0.99` 가
  `네이버 172 × 1.6` 을 이긴다. 물량 많은 증시 기사가 상위를 도배하므로
  **별도 칸으로 뽑는 게 답이다** (실측 raw 배수는 4.05 인데 1.6 으로 잘려 있다)
- 폰 알림에도 이 칸이 맨 위에 온다 (`notify_hunt.py` 의 `china_block`)

### 섹션을 101,105,104 로 넓혔다

경제 섹션만 보면 상위 20개 중 `한국vs해외` 가 **3개**뿐이고 그것도 9·18·19위였다
(증시·기업이 11개로 도배). 세계 섹션은 13개 중 11개를 준다 —
다만 **태반이 트럼프·이란·북핵이라 못 쓴다.** 그래서 `MILITARY_WORDS` 로 군사·외교를 뺀다.
`daily.cmd` 가 `--sid 101,105,104` 로 돌고 실측이 1.5분 → 5분으로 늘었다(예약이라 무방).

**시세·공시 기사는 자동으로 깎이지만 완벽하진 않다.** 추천 전에 제목을 직접 읽고
"30초 안에 뒤집을 알맹이가 있나"를 판단한다 — 이건 스크립트가 못 한다.
**프록시 지표만 보고 답하지 마라. 채널 실적은 `yt-dlp` 로 언제든 받아볼 수 있다.**

## 소재 준비 뒤

`brief.py` 가 `뇌전구_한국\work_econ_<날짜>_<기사id>/` 에 `body.txt` · `real/` · `_sheet_real.jpg` 를 만든다.
**시트는 반드시 눈으로 본다** (규격 1184×880 에 못 미치는 사진이 섞인다).
사진이 모자라면 `--with-siblings` 로 같은 사건 다른 매체 것까지 긁는다.
이후는 기존 뇌전구 파이프라인 그대로 — 240자 이내, 컷 14~17개, 35초 상한.

## 재사용 스크립트 — 전부 `ref_econ/` 에 있다

`hunt.py` (발굴·실측·점수 — `--from-raw` 로 캐시 재사용, `--sid` 로 섹션 추가,
`--group-th` 로 사건 묶는 세기, `--no-fit` 로 채널 배수 끄기) · `brief.py` (소재 준비)
