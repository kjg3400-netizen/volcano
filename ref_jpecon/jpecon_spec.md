# 일본 경제 뇌전구 — 소재 발굴

Yahoo!ニュース 経済에서 **실제로 반응이 붙은** 기사를 찾아 점수순으로 세운다.
한국판(`ref_econ/`)과 구조는 같지만 **대전제 안전 판정**이 하나 더 붙는다.

조사·실측 2026-08-21.

---

## ★한국판보다 조건이 낫다 — 야후는 카테고리가 진짜로 갈린다

한국판에서 제일 고생한 게 "랭킹이 경제로 안 걸러진다"였는데 야후는 그 문제가 없다.

| | 네이버 | 야후 |
|---|---|---|
| 카테고리별 랭킹 | ✗ `sectionId` 무시 | **✓ 진짜로 갈림** |
| 댓글 많은 순 | 전 섹션 뭉뚱그림 | `/ranking/comment/business` 40건 |
| 조회 많은 순 | 전 섹션 뭉뚱그림 | `/ranking/access/news/business` 42건 |
| 추가 신호 | 없음 | はてなブックマーク |

- 코멘트 수는 **기사 페이지 JSON 의 `totalCount`** 에 있다
- 게시 시각은 목록의 `8/20(木) 17:00` 꼴 (연말 넘김은 미래로 나오면 작년으로 본다)
- 하테나는 `b.hatena.ne.jp/entry/jsonlite/?url=` 의 `count` 만 쓴다.
  **0건이면 빈 응답**이 오므로 그냥 파싱하면 죽는다
- 항목 안 텍스트 조각의 **순서가 일정하지 않다**(매체가 제목보다 먼저 오기도 한다).
  위치로 집지 말고 모양으로 가른다 — 시각은 정규식, 제목은 남은 것 중 가장 긴 것

### 물량은 한국보다 훨씬 얇다

한 번 실행에 **66건**뿐이다(한국은 620건). 야후 경제 카테고리 페이지가 10~14건밖에
안 주고, 나머지는 랭킹 80여 건이 전부다. 대신 랭킹에 옛 기사가 섞여 있어
**범위는 149시간치**로 넓다. 하루 1편이면 충분하지만 더 필요해지면
はてなブックマーク `hotentry/economics` 를 소스로 붙여라.

## ★대전제 안전 판정 — 이게 한국판에 없는 부분이다

CLAUDE.md 일본판 대전제는 **비난 금지 · 시청자가 일본인**이다. 그런데
**일본 경제 뉴스는 구조적으로 일본의 어려움 이야기가 많다.** 엔저·물가고·임금정체…
반응만 보고 고르면 자동으로 "일본 경제가 어렵다"가 되고 대전제를 어긴다.

첫 실행에서 실제로 걸린 것:

| 안전도 | 사유 | 소재 |
|--:|---|---|
| −1.00 | 정부+실책, 국민부담 | 총무성이 우편사업 축소를 검토 |
| −0.85 | 정부+실책 | 쿨재팬기구 폐지, 누적적자로 예산요구 보류 (코멘트 180) |
| −0.55 | 실명개인불행 | 배우가 대표인 연예기획사 파산 (코멘트 540) |

**반응이 좋아도 만들 수 없는 것들이다.** 점수를 ±40% 흔드는 게 아니라
`-0.5` 이하면 아예 목록에서 빼고 시트 맨 아래 "만들지 마라" 칸에 따로 적는다.

### 오탐 두 개를 실측으로 잡았다

- **정부가 주어라는 것만으로 깎지 마라.** 대전제가 막는 건 **비난**이지 정부 이야기가
  아니다. `霞が関が国産AIを導入`(코멘트 1,017)이 '国会答弁' 의 `国会` 하나로
  −0.20 을 먹고 3위로 밀렸다. 일본에 좋은 소식인데도. 지금은 **정부 + 실책어**가
  같이 있을 때만 깎는다
- **실명 개인의 불행**은 대전제와 별개지만 이 채널에서 쓸 소재가 아니다.
  `연예기획사 파산＝배우 ○○씨가 대표`(코멘트 540)가 2위로 올라왔었다

### 반대로 올려 주는 꼴

쇼피드 채널 상위 두 편이 **둘 다** `외국이 줄었는데 일본은 늘었다` 였다.
역설이면서 해외 대비인데 **일본이 이긴 쪽**이라 대전제와도 맞는다.

```
7,663회 0.99%  中国客が半減して5210億円消えたのに…逆に売上爆増
5,643회 1.97%  中国人観光客が激減したのに過去最多の344万人   ← 좋아요율 최고
```

`FOREIGN` + `JP_WIN` 이 같이 있으면 +0.55, 역설(`のに`) +0.25, 의문형(`ワケ`·`理由`) +0.15.

## 쓰는 법

```
python ref_jpecon/hunt.py                 # 발굴 (약 20초)
python ref_jpecon/hunt.py --show-unsafe   # 걸러진 것도 같이 본다
python ref_jpecon/hunt.py --from-raw ref_jpecon/out/raw_<시각>.json

python ref_jpecon/brief.py --pick 1       # 고른 사건의 기사·사진·시트 준비
python ref_jpecon/brief.py --url <야후 기사 링크>

python ref_jpecon/seed_seen.py            # 중복목록 갱신 (예약이 매번 부른다)
python ref_jpecon/learn.py --show         # 채널 실적 배수 보기
```

- 결과는 `ref_jpecon/out/_최신시트.md` (시각 박힌 `.md`·`.json` 도 같이 남는다)
- 시트 맨 아래 **"만들지 마라"** 칸을 반드시 읽는다 — 반응 큰 게 거기 있다

## `brief.py` 가 챙기는 것 — 마루가메 회차에서 부딪힌 것들

- 본문은 `<div class="article_body highLightSearchTarget">` 안이다
- 기사 사진은 **`newsatcl-pctr` 호스트만**이다. `news-pctr` 은 사이드바 추천기사고
  `s.yimg.jp` 는 야후 UI 아이콘이다 — 안 거르면 세븐일레븐·고교야구가 딸려 온다
  (실제로 6장 중 5장이 그랬다)
- ★**스톡 크레딧을 경고한다.** 야후 기사 대표사진이 `stock.adobe.com` 인 경우가 흔한데
  그건 **매체가 라이선스한 것**이라 우리가 못 쓴다. 뉴스 사진 인용과는 다른 문제다.
  마루가메 회차는 이것 때문에 12장을 전부 생성했다
- `og:title` 은 `기사제목（매체） - Yahoo!ニュース` 꼴이라 꼬리를 떼야 한다

## 중복목록 — 가나로 가른다

한국·일본 완성본이 한 폴더에 섞여 있다. `seed_seen.py` 는 **가나(ひらがな·カタカナ)가
있는 제목만** 일본 회차로 본다 — 한자만 보면 한국어 제목의 한자와 구별이 안 된다.
`(경제)` 같은 카테고리 꼬리표는 떼고 비교한다.
