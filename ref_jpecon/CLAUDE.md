## 야후는 네이버보다 낫다

**랭킹이 카테고리별로 진짜 갈린다** — 한국판에서 제일 고생한 함정이 여기엔 없다.
코멘트 수는 기사 페이지 JSON 의 `totalCount`, 추가 신호로 はてなブックマーク가 있다.
다만 **물량이 얇다**(한 번에 66건, 한국은 620건).

## ★대전제 안전 판정 — 이게 한국판에 없는 부분이다

일본 경제 뉴스는 **구조적으로 일본의 어려움 이야기가 많다.** 반응만 보고 고르면
자동으로 "일본 경제가 어렵다"가 되어 대전제(비난 금지·시청자가 일본인)를 어긴다.

`-0.5` 이하면 목록에서 빼고 시트 맨 아래 **"만들지 마라"** 칸에 따로 적는다.
**그 칸을 반드시 읽어라 — 반응 큰 게 거기 있다.**

| 깎는 것 | 올리는 것 |
|---|---|
| 정부 **+** 실책어 (−0.85) | 해외가 줄었는데 일본은 늘었다 (+0.55) |
| 국민부담(증세·값인상) (−0.40) | 역설 `のに`·`にもかかわらず` (+0.25) |
| 일본이 진 대비 (−0.70) | 의문형 `ワケ`·`理由`·`なぜ` (+0.15) |
| 실명 개인의 불행 (−0.55) | |

- **정부가 주어라는 것만으로 깎지 마라.** 막는 건 비난이지 정부 이야기가 아니다.
  `霞が関が国産AIを導入`(코멘트 1,017)이 `国会` 한 낱말로 밀렸던 오탐을 고쳤다
- 실명 개인 불행은 대전제와 별개지만 이 채널 소재가 아니다

## ★중국 소재 — 여기도 최고 꼴이지만 **조건이 정반대다**

쇼피드 5편 실측에서 1·2위가 둘 다 중국 편이었다 (중앙 9,500 vs 3,750 = 2.53배).
그런데 한국판처럼 '뺏고 뺏기는 구도'를 쓰면 **대전제 위반**이 된다 — 일본이 지는 이야기다.

터진 두 편은 **일본이 이긴** 구도다:

```
26,000  中国人観光客が激減した「のに」過去最多の344万人
 9,500  中国客が半減して5210億円消えた「のに」逆に売上爆増
 1,200  「日本製」なのに中国産が入る          ← 최저권. 일본이 이긴 이야기가 아니다
```

- **`のに` 하나로 최고 등급을 주면 안 된다.** 1,200 짜리에도 `のに` 가 있다.
  `JP_WIN`(過去最多·爆増·最高益…)이 **함께** 있어야 한다
- **일본이 중국에 밀린 표현은 아예 뺀다** (`CN_LOSE`). safety() 만으로는 안 걸린다 —
  `中国には強気な高市首相がロシアには手も足も出ない…屈辱的な` 가 안전 +0.00 으로
  통과해 후보에 올랐다(실기 2026-08-21). `屈辱`·`手も足も出な`·`奪われ` 까지 잡는다

## ★한국판 배수를 가져다 쓰지 마라

숏단지 최고 꼴이 `한국이 중국에 밀린` 이야기인데, 일본판에서 `日本が負けた` 를 하면
대전제 위반이다. **정반대다.** 쇼피드 상위 두 편은 둘 다
`외국이 줄었는데 일본은 늘었다` — 역설이면서 일본이 이긴 쪽이다.

`learn.py` 는 성숙한 편 5개가 필요한데 아직 3편이라 **배수는 전부 ×1.0** 이고
안전 판정만 돈다. 편이 쌓이면 그때 학습한다.
