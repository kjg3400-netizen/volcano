# 짧뷰 (사장님 본인 채널 — 골프)

## ★★2026-08-29 — **화면 템플릿은 버렸다. 축구(jjack)와 같은 것을 쓴다**

> 「템플릿 원래 칩칩이랑 야구 축구랑 다 똑같은 템플릿으로 하기로 했잖아. **짧뷰 템플릿을 버리고**」

**`골프` 를 부르시면 `ref_jjack/CLAUDE.md` 를 읽고 `jjack_build.py` 로 굽는다.**
칩칩·야구가 그러는 것과 같다 ([[chipchip-reuses-jjack-template]]).
`nono_build.py` · `nono_capcut.py` · `bg_shortview.png` 는 **더 쓰지 않는다.**

| 버린 것 (짧뷰 화면) | 대신 쓰는 것 (jjack 화면) |
|---|---|
| 흰 배경 + 헤더 PNG + 정사각 밴드(972×965) | 검정 띠(y0~521) + 밴드 1080×1399 |
| 노랑 제목 한 줄 | 제목 2줄 (흰색 / 하늘색), **한 줄 7자 이하** |
| 상단효과 없음 | `* 문구 *` 상단효과 (초록1 · 노랑2) |
| 컷을 `clips` 로 배정 | **소스 하나를 통으로** — 컷은 미리 잘라 이어 붙여 준다 |
| 8~14초 · 15초 상한 | jjack 상한 **30초** |
| 프리버드 BGM | jjack 에는 BGM 이 없다 |

**아래 「절대 규격」·「길이와 BGM」·「pan」은 버린 화면의 것이다 — 보지 마라.**
살아 있는 것은 **「제목·설명란」**(174편 메타 조사) 뿐이다. 유튜브 제목·해시태그·설명은
그대로 쓴다 — 숫자를 넣고, 해시태그 8개, 댓글 유도는 살고 구독 유도는 죽는다.

## 부르는 법

> **`<링크> 골프`**  ·  `<클립 경로> 짧뷰로 줘`

되묻지 말고 끝까지 진행한다. 소재만 주시면 프레임을 보고 대본까지 쓴다.
**볼케이노 MCP 를 쓰지 않는다.** `volcano_video` 를 부르지 마라. 로컬 ffmpeg + ASS 로 끝난다.

### 소재가 링크로 올 때

사장님은 보통 **링크를 주신다.** 먼저 원본 해상도로 받아 workdir 에 넣고 그걸 소스로 쓴다.

```
python -m yt_dlp --no-update -f "bv*+ba/b" --merge-output-format mp4 -o "<workdir>/src.mp4" "<링크>"
```

받은 뒤 **프레임을 Read 로 직접 봐서** 무슨 상황인지 읽고 대본을 쓴다.
밴드가 정사각이라 세로 소재는 위아래가 크게 잘린다 — 어디를 남길지 프레임 보고 정한다.

## ★납품 형태 — 캡컷 드래프트다. 되묻지 않는다

축구와 같다 — **기본 납품은 캡컷 드래프트**고, mp4 는 사장님이 **`mp4로 줘`** 라고
따로 말씀하실 때만 굽는다 (2026-08-19 지시).

**`nono_capcut.py` 를 2026-08-21 에 만들었다** (골프볼 회차). 새로 짜지 마라.
`jjack_capcut.py` 를 import 해 쓰고 화면 구성만 갈아끼운 것이라 짧다.

- 검정 띠가 없다 → **흰 배경+헤더 PNG 가 영상 '아래'** 로 간다 (축구는 띠가 '위')
  배경 한 장은 `ref_nono/assets/bg_shortview.png` 에 구워 뒀다 — 지우면 생성기가 죽는다
- 영상이 화면을 안 채운다 → 소스를 **1:1 로 미리 크롭**해 `capcut_source` 로 준다.
  캔버스 스케일 0.9, 세로 이동 +0.0427 (밴드 중심 y919 → 정규화)
- 제목은 **노랑 한 줄** — 본에 `#F9EF4D` 가 없어 흰색을 복제해 색만 갈았다
- **`clips` 를 컷 조각으로 올린다** (축구는 통짜). 조각 길이 = 배정된 자막 span + GAP,
  마지막 조각만 + TAIL — `nono_build` 와 같은 셈법이라야 mp4 와 어긋나지 않는다
- **자막 줄나눔은 `sub.ass` 에서 읽어 온다.** 글자수로 다시 접으면 빌더와 갈린다

### ★`font_size` 는 여전히 눈으로 확인받을 값이다

캡컷 단위와 ASS 픽셀의 환산비 `CC_PER_ASS = 6.13` 하나로 푼다. 축구 보정쌍
(자막 `미친 탄력으로…` ↔ 11.0)에서 나온 값이고, **이걸로 계산한 제목 10.4 가
빌더 실측 fontsize 63 과 맞아떨어져** 근거는 선다. 다만 이 채널 본 프로젝트로
직접 잰 값은 아니다 — 캡컷에서 열어 보고 크면 이 상수만 고치면 된다.

시작 전에 `ref_nono/nono_spec.md` 를 읽는다. 아래는 요약이다.
(채널 `@shortview` `UCd8NpX-szthcjWrGmID4BoA` 쇼츠 **174편 전수 메타** + 8편 픽셀 실측, 2026-08-18)

## 한 줄 요약

**흰 배경에 [헤더] · [노랑 제목 한 줄] · [정사각 영상] · [하단 자막] 네 칸을 쌓는다.**
TTS 는 축구와 **완전히 같다**(준기·angry·1.1배). 다른 건 화면뿐이다 —
검정 띠가 없고, 영상이 화면을 안 채우고, 제목이 영상 위가 아니라 **위쪽 흰 칸에** 있다.

| 제목 | **G마켓 산스 TTF Medium**, 노랑 `#F9EF4D` + 검정 외곽선 10 + 그림자 3, 잉크중심 **y370** |

## ★★첫 줄만 읽는다 — 나머지는 자막만 (사장님 지시 2026-08-28)

> 「왜 tts가 또 다 풀 tts냐 처음만 tts하고 남어지 다 자막이지」

루트 CLAUDE.md 클립채널 표의 「목소리 — 첫 줄만 준기」가 이 채널에도 그대로다.
축구 빌더엔 2026-08-27 에 들어갔는데 골프 빌더에만 빠져 있어서 한 번 틀렸다.

- **빌더 기본값이 '첫 줄만 읽는다' 다** (`is_silent`). job 에 아무것도 안 적어도 그렇게 된다
- 더 읽히려면 그 줄에 `"silent": false`, 첫 줄도 빼려면 `"silent": true`
- 무음 줄 길이는 글자수로 잡는다 — `글자수 x 0.1208 + 0.055` (축구 빌더 회귀값)
- 대본 출력에 `★읽음` / `자막` 으로 찍히니 굽기 전에 눈으로 확인해라
- ★**읽는 줄이 하나뿐이면 음악이 소리를 거의 다 차지한다.** 그래서 음악을
  나레이션으로 덕킹한다. 예전에 덕킹으로 바닥이 -40 까지 내려간 적이 있는데 그건
  컷 사이가 0.10초일 때 얘기다 — 지금은 회복할 시간이 넉넉해 같은 함정이 아니다

## ★자막·워터마크가 구워진 소재 (인스타 립 등) — 미리 정사각으로 잘라서 준다

2026-08-29 레이저퍼터 편 실기. 720x1280 인스타 소재에 **원 게시자 자막(y185~250)** 과
**`[광고]` 워터마크(y47~77)** 가 박혀 있었다. 밴드가 정사각이라 소스 세로의 715px 만
쓰는데, `pan >= 0.45` 면 둘 다 프레임 밖으로 나간다 — **골프는 잘라내는 쪽이 먼저다**
(축구와 달리 세로 여유가 크다. [[jjack-precrop-burned-in-caption-source]] 와 반대 상황).

**컷마다 pan 이 다를 때는 `sq.mp4` 한 장에 시간축으로 구워 넣는다.** 캡컷 드래프트는
클립마다 pan 을 못 준다 — 세그먼트마다 스케일·위치가 하나로 박혀 있어서, 빌더에만
`pan` 을 주면 **mp4 와 드래프트의 화면이 갈린다.**

```
# 1) 소리 지우고 가림막만 뭉갠다 (보험 — pan 으로 이미 잘려 나가지만)
ffmpeg -i src_raw.mp4 -/filter_complex _clean.txt -map "[v]" -an -c:v libx264 -crf 16 src_clean.mp4
# 2) 컷별 pan 을 crop 의 y 식에 박아 1:1 로 자른다. 720x715 = 965/1.35
#    ★ffmpeg 9 는 crop 의 eval 옵션을 없앴다 — 식은 기본이 프레임마다 다시 계산이다
crop=w=720:h=715:x=0:y='if(lt(t,4.2),322,if(lt(t,6.37),407,...))'
```

- **경계는 소스의 컷 자리에 맞춘다** — `select='gt(scene,0.10)'` 로 먼저 뽑는다
- 원본 y = `565.19 x pan` (밴드 972x965 · k=1.35 에서 나온 값)
- 만든 `sq.mp4` 를 `clips[].path` 와 `capcut_source` **둘 다**에 준다.
  빌더가 다시 스케일해도 k=1.35 라 1:1 로 맞아 pan 은 안 먹는다(0.5 그대로 둬라)
- **오디오는 소스에서 아예 뺀다**(`-an`). `src_vol` 은 loudnorm 이 되올려서 못 믿는다
  ([[jjack-srcvol-and-flow-knobs-are-noops]]) — 스트림이 없으면 빌더가 `anullsrc` 를 넣는다

## ★읽는 줄이 하나뿐이면 `bgm_trim` 을 올려야 한다

BGM 볼륨을 `첫 wav 의 LUFS - 곡 LUFS + bgm_trim` 으로 잡는데, 회차가 길어지면
완성본 통합은 그 한 줄이 끌어올리고 음악은 그대로라 **`음악이 완성본보다 4 LU 아래`가
미달로 뜬다.** 21.9초 회차에서 9.7 LU 아래로 앉았고 `"bgm_trim": 7.1` (기본 1.4) 로 맞았다.
**`--check` 가 잡아 주니 한 번 굽고 값만 고쳐 `--no-tts` 로 다시 구우면 된다.**

## ★세로 크롭 위치 — `pan` (사장님 지시 2026-08-28)

> 「영상이 일단 첫 시작할때 하단이 안보여서 공이 안보여」

밴드가 정사각이라 9:16 소재는 가운데만 남는다. **공이 발밑에 있으면 잘려 나간다.**

- 클립마다 `"pan"` 으로 고른다 — **0 위 · 0.5 가운데(기본) · 1 아래**
- job 최상단에 `"pan"` 을 두면 전 클립 기본값이 된다
- 티샷·퍼팅처럼 **공이 바닥에 있는 컷은 0.75~0.8** 로 내려라.
  다만 너무 내리면 사람 머리가 잘린다 — 굽고 나서 밴드만 잘라 눈으로 봐라:
  `ffmpeg -i out/v001.mp4 -vf "fps=1.2,crop=1080:965:0:437,scale=420:-1,tile=5x1" _band0.jpg`

## ★길이와 BGM — 2026-08-28 사장님 지시

> 「영상 시간 15초 이내로 다 끊기 최대 14초 최단 8~9초.
>  그리고 영상에 항상 지금 free 버드 음악이 들어가있음」

- **길이 8~14초가 기본.** 컷 5~9개 · 컷당 1.5~2.0초면 들어온다.
  빌더가 14.99초에서 막고, 8초 미만·14초 초과는 경고를 낸다
  (옛 규격 「13~16초」는 조회 통계였다 — 지금은 이 지시가 우선이다)
- ★**2026-08-29 완화** — 「골프형도 컨셉 지금 바꾸면서 시간초를 15초 이내로 꼭 안 잡아도 돼」.
  그래도 **게이트는 그대로 두고 회차별로만 연다** — job 에 `"max_sec": 25` 처럼 적으면
  그 회차만 통과한다. 안 적은 회차는 예전대로 14.99초에서 막힌다
  ([[volcano-dont-remove-the-tool-to-avoid-the-defect]] 대로 수단을 지우지 않는다).
  길게 갈 때도 컷당 1.3~1.8초 리듬은 그대로 두고 컷 수만 늘려라
- **BGM 은 기본이 '넣는다' 다.** 음원이 없으면 빌더가 굽지 않고 멈춘다.
  이번 편만 빼려면 job 에 `"bgm": false`, 다른 곡이면 `"bgm": "<경로>"`
- **첫 TTS 와 같이 시작하되 4 dB 낮춰 들어가 점점 커진다** (`BGM_IN_DOWN`).
  음악만 먼저 들리는 머리는 **없다** — 사장님이 정정하신 부분이다
- **곡은 25초 지점부터 쓴다** (`BGM_IN`) — 앞 15초가 몸통보다 3.5 dB 조용하다
- **크기는 `_bgm.wav`(음악 갈래)의 통합 라우드니스로만 잰다.** 완성본에서도,
  갈래의 momentary 꼬리로도 안 된다 — 둘 다 음악이 아닌 것을 본다
- 음악은 **완성본보다 5 LU 아래**(-19 LUFS). 크면 `BGM_TRIM` 을 내려라
- 완성본은 **-14.0 LUFS** 로 못박힌다 (2패스 보정)
- ★**옛 8편(2026-06 이전)에는 BGM 이 없다.** 그걸로 소리를 맞추지 마라
- ★**캡컷 드래프트의 BGM 은 아직 평평하다** — 오름세는 mp4 쪽에만 들어갔다

## 축구와 다른 점만 추리면

- 제목이 **한 줄**이고 **노랑**이다 (축구는 2줄 흰색/하늘색)
- 하단 자막 첫 컷 **주황 강조가 없다.** 전부 흰색이다
- **상단효과(`* 문구 *`)가 없다**
- 밴드 안에서 **컷이 갈린다** (축구는 통짜). 전환이 자막 교체 시점과 대체로 맞물린다
  → job 에 `clips` 로 자막 컷 번호에 클립을 배정한다. 소스 하나면 `source` 로 통짜

## ★자막 세로 보정 — 빼먹으면 5px 위에 앉는다

ASS 의 `\an5` 는 잉크가 아니라 **글자 상자** 기준이라 주아체는 5px 어긋난다.
`nono_build.py` 의 `calib_sub()` 가 **회색 바탕**에 찍어 재고 밀어준다.
검정 바탕에 찍으면 안 된다 — 검정 외곽선이 배경과 같은 색이라 안 보인다.

검증 창도 **밴드 아래끝(y1401)보다 밑에서 시작**해야 한다. `SUB_CY-120`(y1376)으로
잡으면 어두운 영상의 밴드 밑단이 딸려 들어와 40px 넘게 틀린 값이 나온다 — 한 번 오검출했다.

## 제목·설명란

- **화면 제목과 유튜브 제목은 다르다.** 화면 쪽이 짧고 세다
- **숫자를 넣어라** — 34편 중앙 61,792 vs 없는 140편 33,342 (1.85배)
- 사는 부품 `구력` `전설` `레전드` `클럽` `퍼팅` `골프채` (다만 표본 3~5편이라 배수는 못 믿는다)
  / 죽는 부품 `스윙`(25편 3.2만) `ㅋ`(23편 3.4만) `역대급`(13편 3.4만) — 이쪽은 표본이 단단하다
- 해시태그는 **마지막 한 줄에 몰아쓰고 8개**로 맞춘다 (7개가 최빈이나 8개가 최고). 10개 넘으면 내려감
- **댓글 유도는 살고 구독·좋아요 유도는 죽는다**
- 유튜브 태그(tags)는 안 쓴다. 카테고리 `People & Blogs`

## 하는 일 순서

1. 소스 클립 프레임을 **Read 로 직접 본다.** 무슨 상황인지 눈으로 읽어낸다
2. 노랑 제목 1줄 + 자막 대본 5~9컷(**8~14초**) 을 쓴다
3. `job.json` 쓰고 `python nono_build.py job.json` — TTS 를 만든다.
   컷을 나누려면 `clips`, 캡컷용으로 **1:1 크롭한 소스를 `capcut_source`** 에 적는다
4. `python nono_capcut.py job.json --name "이름"` → 답변 끝에 **캡컷 프로젝트 경로**와
   "캡컷을 껐다 켜야 목록에 뜬다" 를 적는다
5. `mp4로 줘` 라고 하셨을 때만 3번에 `--check` 를 붙여 굽고
   `python deliver.py <workdir> "<유튜브 제목>"` 로 납품한다
