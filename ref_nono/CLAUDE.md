# 짧뷰 (사장님 본인 채널 — 골프. 축구와 형제지만 화면이 다르다)

## 부르는 법

> **`<링크> 골프`**  ·  `<클립 경로> 짧뷰로 줘`

**`골프` 는 이 채널(짧뷰)이다. JJACK_J 가 아니다** — 그쪽은 `축구`·`잭제이` 로 부르신다.
(`work_jjack_golf` 같은 폴더가 있어 헷갈리기 쉬우니 낱말로만 갈라라.)

되묻지 말고 끝까지 진행한다. 소재만 주시면 프레임을 보고 대본까지 쓴다.
**볼케이노 MCP 를 쓰지 않는다.** `volcano_video` 를 부르지 마라. 로컬 ffmpeg + ASS 로 끝난다.

### 소재가 링크로 올 때

사장님은 보통 **링크를 주신다.** 먼저 원본 해상도로 받아 workdir 에 넣고 그걸 소스로 쓴다.

```
python -m yt_dlp --no-update -f "bv*+ba/b" --merge-output-format mp4 -o "<workdir>/src.mp4" "<링크>"
```

받은 뒤 **프레임을 Read 로 직접 봐서** 무슨 상황인지 읽고 대본을 쓴다.
밴드가 정사각이라 세로 소재는 위아래가 크게 잘린다 — 어디를 남길지 프레임 보고 정한다.

## ★납품 형태 — 캡컷 드래프트다. 되묻지 않는다

축구와 같다 — **기본 납품은 캡컷 드래프트**고, mp4 는 사장님이 **`mp4로 줘`** 라고
따로 말씀하실 때만 굽는다 (2026-08-19 지시).

**`nono_capcut.py` 를 2026-08-21 에 만들었다** (골프볼 회차). 새로 짜지 마라.
`jjack_capcut.py` 를 import 해 쓰고 화면 구성만 갈아끼운 것이라 짧다.

- 검정 띠가 없다 → **흰 배경+헤더 PNG 가 영상 '아래'** 로 간다 (축구는 띠가 '위')
  배경 한 장은 `ref_nono/assets/bg_shortview.png` 에 구워 뒀다 — 지우면 생성기가 죽는다
- 영상이 화면을 안 채운다 → 소스를 **1:1 로 미리 크롭**해 `capcut_source` 로 준다.
  캔버스 스케일 0.9, 세로 이동 +0.0427 (밴드 중심 y919 → 정규화)
- 제목은 **노랑 한 줄** — 본에 `#F9EF4D` 가 없어 흰색을 복제해 색만 갈았다
- **`clips` 를 컷 조각으로 올린다** (축구는 통짜). 조각 길이 = 배정된 자막 span + GAP,
  마지막 조각만 + TAIL — `nono_build` 와 같은 셈법이라야 mp4 와 어긋나지 않는다
- **자막 줄나눔은 `sub.ass` 에서 읽어 온다.** 글자수로 다시 접으면 빌더와 갈린다

### ★`font_size` 는 여전히 눈으로 확인받을 값이다

캡컷 단위와 ASS 픽셀의 환산비 `CC_PER_ASS = 6.13` 하나로 푼다. 축구 보정쌍
(자막 `미친 탄력으로…` ↔ 11.0)에서 나온 값이고, **이걸로 계산한 제목 10.4 가
빌더 실측 fontsize 63 과 맞아떨어져** 근거는 선다. 다만 이 채널 본 프로젝트로
직접 잰 값은 아니다 — 캡컷에서 열어 보고 크면 이 상수만 고치면 된다.

시작 전에 `ref_nono/nono_spec.md` 를 읽는다. 아래는 요약이다.
(채널 `@shortview` `UCd8NpX-szthcjWrGmID4BoA` 쇼츠 **174편 전수 메타** + 8편 픽셀 실측, 2026-08-18)

## 한 줄 요약

**흰 배경에 [헤더] · [노랑 제목 한 줄] · [정사각 영상] · [하단 자막] 네 칸을 쌓는다.**
TTS 는 축구와 **완전히 같다**(준기·angry·1.1배). 다른 건 화면뿐이다 —
검정 띠가 없고, 영상이 화면을 안 채우고, 제목이 영상 위가 아니라 **위쪽 흰 칸에** 있다.

## 절대 규격 (8편 픽셀 실측, 편차 ±5px)

| | |
|---|---|
| 해상도 | 1080×1920 · 30fps |
| 길이 | 9~33초. **13~16초가 정답** (85편 평균 27.9만). 빌더 상한 25초 |
| 배경 | **순백 `#FFFFFF`** |
| 헤더 | `(90,138)` 에 410×168 고정 PNG — 8편 전부 같다 |
| 제목 | **G마켓 산스 TTF Medium**, 노랑 `#F9EF4D` + 검정 외곽선 10 + 그림자 3, 잉크중심 **y370** |
| 영상 밴드 | **x54~1025 · y437~1401 = 972×965 (거의 정사각)** |
| 하단 자막 | **주아체**, 흰색 + 검정 외곽선 7, 잉크중심 **y1496**, 2줄이면 줄간격 77 |

**밴드가 정사각이라 세로 소재는 위아래가 크게 잘린다.** 가로·정사각 소재를 골라라.
**길이는 짧을수록 좋다** — 20초를 넘기면 성과가 꺾인다. 13~16초에 붙여라.

## 축구와 다른 점만 추리면

- 제목이 **한 줄**이고 **노랑**이다 (축구는 2줄 흰색/하늘색)
- 하단 자막 첫 컷 **주황 강조가 없다.** 전부 흰색이다
- **상단효과(`* 문구 *`)가 없다**
- 밴드 안에서 **컷이 갈린다** (축구는 통짜). 전환이 자막 교체 시점과 대체로 맞물린다
  → job 에 `clips` 로 자막 컷 번호에 클립을 배정한다. 소스 하나면 `source` 로 통짜

## ★자막 세로 보정 — 빼먹으면 5px 위에 앉는다

ASS 의 `\an5` 는 잉크가 아니라 **글자 상자** 기준이라 주아체는 5px 어긋난다.
`nono_build.py` 의 `calib_sub()` 가 **회색 바탕**에 찍어 재고 밀어준다.
검정 바탕에 찍으면 안 된다 — 검정 외곽선이 배경과 같은 색이라 안 보인다.

검증 창도 **밴드 아래끝(y1401)보다 밑에서 시작**해야 한다. `SUB_CY-120`(y1376)으로
잡으면 어두운 영상의 밴드 밑단이 딸려 들어와 40px 넘게 틀린 값이 나온다 — 한 번 오검출했다.

## 제목·설명란

- **화면 제목과 유튜브 제목은 다르다.** 화면 쪽이 짧고 세다
- **숫자를 넣어라** — 34편 중앙 61,792 vs 없는 140편 33,342 (1.85배)
- 사는 부품 `구력` `전설` `레전드` `클럽` `퍼팅` `골프채` (다만 표본 3~5편이라 배수는 못 믿는다)
  / 죽는 부품 `스윙`(25편 3.2만) `ㅋ`(23편 3.4만) `역대급`(13편 3.4만) — 이쪽은 표본이 단단하다
- 해시태그는 **마지막 한 줄에 몰아쓰고 8개**로 맞춘다 (7개가 최빈이나 8개가 최고). 10개 넘으면 내려감
- **댓글 유도는 살고 구독·좋아요 유도는 죽는다**
- 유튜브 태그(tags)는 안 쓴다. 카테고리 `People & Blogs`

## 하는 일 순서

1. 소스 클립 프레임을 **Read 로 직접 본다.** 무슨 상황인지 눈으로 읽어낸다
2. 노랑 제목 1줄 + 자막 대본 5~9컷(13~16초) 을 쓴다
3. `job.json` 쓰고 `python nono_build.py job.json` — TTS 를 만든다.
   컷을 나누려면 `clips`, 캡컷용으로 **1:1 크롭한 소스를 `capcut_source`** 에 적는다
4. `python nono_capcut.py job.json --name "이름"` → 답변 끝에 **캡컷 프로젝트 경로**와
   "캡컷을 껐다 켜야 목록에 뜬다" 를 적는다
5. `mp4로 줘` 라고 하셨을 때만 3번에 `--check` 를 붙여 굽고
   `python deliver.py <workdir> "<유튜브 제목>"` 로 납품한다

## 재사용 스크립트

`nono_build.py` (빌더 — 규격이 기본값으로 박혀 있고 `--check` 로 배경·밴드·헤더·제목·자막·
움직임 자가검증. `--no-tts` 는 캐시만 쓴다)
· **`nono_capcut.py` (캡컷 드래프트 생성기 — 기본 납품. 검증은 축구 것 `jjack_ccheck.py`)**
· 자산 `ref_nono/assets/bg_shortview.png`(흰 배경+헤더) · 조사 스크립트는 `ref_nono/`
· 예제 job 은 `골프/work_nono_test/job.json`, 컷·캡컷 예제는 `골프/work_nono_balltest_0821/job.json`
· 납품은 기존 `deliver.py`

★**`--check` 의 '밴드' 항목은 밝은 화면에서 거짓 미달이 뜬다.** 흰 실험복·흰 배경이
소재에 있으면 밴드 위끝을 흰 바탕과 못 가려 436 대신 474 로 잡는다. 빌더 필터는
`scale=972:965` → `overlay=54:437` 로 **좌표가 박혀 있어 어긋날 수가 없다** —
의심되면 `filter.txt` 를 보고 넘어가라 (2026-08-21 실측).
