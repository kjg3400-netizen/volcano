### 금지

- **장식 효과를 얹지 마라** — 글리치·흔들기·플래시 따위. 화면은 규격대로만 간다
- ★★**움직이는 슬로우 줌을 넣지 마라. 고정 크롭이다** (재정정 2026-08-23 저녁).
  본 채널 원본에는 슬로우 줌이 걸려 있고 그건 실측이 맞다. 그런데 그대로 구웠더니
  사장님이 「**누가 줌을 이렇게 촌스럽게 하냐. 크롭을 완전 땡기라는 거지**」 하셨다.
  → 컷마다 **고정 크롭.** 애니메이션은 없다. `zoomplan.json` 에 `"mode":"fixed"` + 샷마다 `crop`
- ★★**그런데 3~5배는 과했다 — 상반신으로 내려라** (재정정 2026-08-23 밤).
  3~5배로 구웠더니 **여섯 컷 중 다섯이 이마가 잘렸고** 사장님이
  「**크롭이 너무 과하다. 어떤 사람이 말하는지 얼굴은 좀 보여줘야지**」 하셨다.
  → **머리 위 여백 + 어깨선**이 들어오는 상반신 크롭이다. **배율을 목표로 삼지 마라** —
  인물 크기가 소스마다 달라 같은 배율이 곧 다른 화면이 된다. 맞출 것은 비율이다:
  `창높이 = 머리높이/0.55` · `창 위끝 = 정수리 − 0.11×창높이`. 실제로 1.6~3.1배가 나왔다.
  샷에 `"head":[정수리y,턱y,얼굴중심x]` 를 같이 적으면 `--check` 가 직접 잰다
- **크롭 사각형은 시트를 보고 눈으로 정한다** — 얼굴검출은 수화 통역사를 집고
  분할화면의 화자를 못 가른다. 직접 짠 살빛 검출도 목·와이셔츠까지 내려가 못 쓴다.
  ★**격자는 40px 로 읽어라** — 120px 격자로 읽다가 정수리를 144px 틀렸고 그게 그대로
  잘린 크롭이 됐다 (`headread.py`)
- ★**로고는 세로로도 피해진다.** 국회방송 로고는 y45~100 에만 있어 크롭 위끝이 100 보다
  아래면 x 와 무관하게 화면 밖이다. 가로 조건만 걸면 쓸 자리를 스스로 좁힌다
- ★**우상단 국회방송 로고는 크롭으로 밀어낸다.** 지키는 게 아니다(사장님 지시).
  같이 잘려 나가는 **원본 이름자막 리본**의 이름·소속·날짜는 정보블록 `credits` 로,
  로고가 지던 **출처 표시**는 고지줄(`▪ 출처 국회방송 · 일부 편집되었습니다 ▪`)로 옮긴다
- ★**스튜디오 앵커 컷은 넣지 마라** — 「굳이 필요하지도 않다」(지시 2026-08-23).

## 하는 일 순서

1. 소스 클립 프레임을 **Read 로 직접 본다.** 무슨 상황인지 눈으로 읽어낸다
2. `python ref_maeil/asr_subs.py clip.mp4 --into job.json` 로 발화를 받아쓴다
   (★whisper 구간 누락 함정이 여기도 그대로다 — 커버리지를 재라)
3. 헤드라인 2줄 + 카드(배지·인용줄·대문짝) + **나레이션 3줄**을 쓴다
4. ★**컷마다 고정 크롭 사각형을 정한다** — `headread.py` 로 40px 격자를 뽑아 정수리·턱을
   읽고, `cropplan.py` 가 상반신 셈으로 사각형을 낸 뒤 **밴드 그림 그대로 시트를 눈으로 보고**
   `zoomplan.json`(`mode:"fixed"` + `crop` + `head`)에 적는다.
   잘려 나가는 이름·소속·날짜는 `credits` 로 옮긴다
5. `python ref_poli/poli_build.py job.json --check`
6. **완성본 컷 시트(`outsheet.py`)를 눈으로 본다** — 자막까지 얹힌 실제 화면이다
7. `python deliver.py <workdir> "<유튜브 제목> (정치)"`
