## 축구와 다른 점 — 제목(검정 띠)뿐이다. 자막은 축구와 같다

**★이 둘을 헷갈리지 마라.** 2026-08-19 에 제목의 체언종지를 보고 자막까지 그럴 거라
넘겨짚었다가 프레임을 보고 뒤집혔다.

### 제목 (검정 띠 2줄) — 축구와 다르다

축구는 `~하고 있다는데?` 지만 칩칩 제목은 **두 줄 다 체언종지(명사 끝)** 다.
**1줄이 수식절, 2줄이 핵심 명사구**로 갈린다.

```
1줄(흰색)    피지컬을 잊게 만드는     ← ~는/~한 으로 끝나는 수식절
2줄(하늘색)  압도적인 춤선           ← 핵심 명사구
```

- 한 줄 6~10자, 두 줄 합쳐 15~20자
- 어휘: `독보적` `압도적` `확신의` `역대급` `절대` `기죽이는` `장악하는` `잊게 만드는`
- 원본이 크게 터졌으면 앞에 **`(2000만뷰)`** 처럼 원본 조회수를 박는다

### 하단 자막 — 축구와 똑같다

첫 컷은 **`~다는데?` · `~라는데?` 후킹 + 주황 강조**다. 프레임 실측 4편 중 3편이 그렇다.

```
뒤 댄서들 [기를 다 죽여놨]다는데?     ← 주황이 가운데
[유치원이] 난리가 났다는데?           ← 주황이 앞
[확신의 센터 상]이라는데?
```

`jjack_build.py` 는 `hl` 이 문장 앞이든 중간이든 다 처리한다. 둘째 컷부터는 색 없이 흰색이다.
주황을 안 쓰는 회차도 있다(`VVmz8_77X4A` 는 전부 흰색) — 빌더는 첫 컷 `hl` 이 없으면
**경고만 하고 통과**시키니 그대로 두면 된다.

- 길이는 **11.7~20.9초** (축구 12.8~15.5초보다 조금 길다). 빌더 상한 30초에 안 걸린다
- 한국어판과 영어/일본어판을 따로 올린다

## ★소재 조달 — 이 채널의 진짜 병목이다

칩칩 소재는 전부 **타 채널 원본**이다. 재포장은 세 가지가 동시에 걸린다 —
유튜브 **재사용 콘텐츠 정책**(수익화), **Content ID**, 그리고 다수가 **미성년 등장**이다.
허락 없는 클립으로 완성본을 만들지 마라. 만들어 드려도 채널 쪽이 위험해진다.

- **학원·단체 원본(발레학원·유치원·댄스학원)은 허락이 잘 난다** — 홍보가 목적이라 서로 이득이고,
  한 번 받으면 그 채널이 통째로 열린다. 요청 메일 본은 `ref_chipchip/permission_email.md`
- **개인 크리에이터 채널은 어렵다** — 본인 채널 수익이 사업이라 승낙 유인이 없다
- 소재 후보는 `sheet_hunt.py` 로 썸네일 시트를 뽑아 눈으로 고른다

## ★★쇼츠 발굴의 유일한 문 — 검색 페이지 원본 HTML

```

```

- `sp=EgIYAQ==`(4분 미만)만 `shortsLockupViewModel` 을 준다. 한 질의에 25~40건

## ★상황판 — 한 장으로 다 본다

```
board.cmd            (볼케이노 폴더에서 더블클릭 — 새로 받아 브라우저로 연다)
python ref_chipchip/board.py --full --open
python ref_chipchip/board.py                 # 내 채널·트렌드만 (빠름)
```

`ref_chipchip/out/board.html` 에 여섯 칸이 한 화면에 나온다 —
**오늘 쓸 소재 · 급상승 · 달아오른 채널 · 내 채널 둘 · 유사경쟁(레이더) · 실시간 트렌드**.
썸네일을 누르면 유튜브로 바로 열린다. ref_ 폴더를 뒤질 일이 없다.

## ★★유튜브 RSS 를 쓰지 마라 — 몰아치면 IP 단위로 404 가 된다

`feeds/videos.xml?channel_id=` 을 **채널 111곳에 연달아** 때렸더니 그 엔드포인트가
막혔다(2026-08-21). **내 채널까지 404** 였고 같은 IP 에서 `/shorts`·검색·구글트렌드는
전부 200 이었다. 하루 이틀 쉬면 풀리지만 코드로는 못 푼다.

- **`/shorts` 페이지 하나로 대신한다** — 최신순 + 조회수를 같이 주므로 게시일 대신
  '앞에서 몇 번째'를 신선도로 쓴다. 요청도 채널당 2회에서 1회로 준다
- **오류 페이지를 크기로 판정하지 마라.** 유튜브 404 는 1,613바이트 HTML 이라
  `size > 800` 을 통과했고, 파서가 조용히 0건을 내며 캐시 179개 중 95개를 오염시켰다.
  `fetch()` 가 이제 내용을 보고 걸러 지운다
